希望于大家有益

fnp:find name path,它采用预缓存的方式,把常用文件缓存起来,没有后台轮询,索引效率直逼O(1)的理论下限,可以使用短名方式fnp o直接得到绝对路径,还有ff配合它做索引更新,也能一键重建索引,更改或添加索引

ff:file and floder,它通过统一的方式,把文件处理的常见操作做了一个聚合,涉及压缩/移动/重命名/新建/预览/多选/管道/删除,还能配合fnp来索引更新,操作心智是统一的$1表示路径查找,$2是模式词与参数

t:text,它集成了常见的文件处理意图,首先分为选择/打印/跳转,也就是spf三种,聚合了执行,复制,输出,行末,搜索,覆盖,替换,不必从编辑器内部,简单文本操作意图可以有更轻便的方式达成目的

asts:通过ast,自动列举你所写过的函数,当代码有误时,可以指出在哪处有问题,而非shell模糊报错,可以提供精简版(cu)帮你去掉样板过滤出代码里面更有价值的一部分信息
